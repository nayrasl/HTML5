Como inserir imagem no texto e ícone na aba do site

Com IMG insere a imagem e com GIMP consegue redimensionar e editar a imagem antes de inserir no site. Atenção as imagens devido aos direitos autorais.

Dicas: para selecionar imagens no VS Code: teclas CTRL + espaço.

Para colocar ícone na aba do site, precisa de uma imagem com a extensão .ico que pode ser criada no site Favicon.io ou imagem já formatada no site Icon archive. E deve ser inserido pelo cabeçalho <head > no código.

É claro que a vida é boa

E dentro da tag colocar a URL da citação com o comando cite= exemplo: <blockquote style="color:rgb(242, 32, 67);" cite = "https://www.culturagenial.com/poemas-sobre-a-vida-escritos-por-autores-famosos/#google_vignette">

Trabalhando com listas

Listas Ordenadas

Usa-se <ol> para uma lista ordenada e <li> para especificar as linhas. Como por exemplo:

  1. Primeiro item
  2. Segundo item
  3. Terceiro item
  4. Quarto item
  5. Quinto item

Tem como colocar também o tipo, letra ou númerico com a função 'type' e de qual número ou letra quer iniciar, com a função 'start'.

Listas não ordenadas

Usa-se <ul> e não seguem uma sequência, como por exemplo:

  • Arroz
  • Feijão
  • Abacate
  • Espinafre

Listas Mistas

Tem como usar lista ordenada dentro de lista ordenada e Lista Ordenadas misturadas com listas não ordenadas.Como no exemplo a seguir:

  1. Primeiro item
    1. Primeiro
    2. Segundo
    3. Terceiro
  2. Segundo item
    • 1
    • 7
    • 5
  3. Terceiro item
  4. Quarto item
  5. Quinto item

    Imagens Dinâmicas

    Tente abrir esse site em vários dispositivos ou aumente e diminua o tamanho do seu navegador.

    Com as tags picture e source pode colocar a imagens com tamanhos diferentes para elas se adaptarem ao tamanho do navegador.

    Adcionando áudio no site

    Pode baixar áudio da biblioteca do Youtube Creator, desde que confira antes os direitos autorais. A tag utilizada é audio e parâmetros controls e autoplay. Os formatos existentes são MP3, WAV E OGG, portanto depende muito do navegador.

    Outra maneira é usando source com os formatos de áudio igual a imagem.

    Adcionando vídeo no site

    Os formatos de vídeo nativamente aceitos no HTML5 são MP4 (.mp4), WebM (.webm) e Ogg (.ogv). O MP4 com codec H.264 é o mais compatível entre navegadores e dispositivos móveis, enquanto o WebM oferece alta qualidade com menor tamanho de arquivo. Recomenda-se fornecer múltiplas fontes para garantir compatibilidade. As tags necessarias são:
    video controls source src="video.webm" type="video/webm" source src="video.mp4" type="video/mp4" Seu navegador não suporta vídeos em HTML5. /video
    DICA PARA CONVERSOR DE VÍDEO: HandBrake Consumo é alto quando são hospedados no site.

    Adcionando vídeos de plataforma externa

    Consome menos espaço no site, quando extraídos de plataformas como o Youtube. A forma mais simples (e correta) de colocar um vídeo do YouTube no seu site é usando o iframe> — não use video> com link do YouTube, porque não funciona (o YouTube não fornece o arquivo direto, só o player).
    Método padrão (incorporar vídeo) 1. Vá no vídeo no YouTube 2. Clique em “Compartilhar” → “Incorporar” 3. Copie o código

    OBSERVAÇÃO: O player do YouTube não funciona corretamente em arquivos locais (file://) por questões de segurança (CORS / origem). Ele precisa de um servidor (http:// ou https://) para rodar. ✅ Como resolver (bem simples) ✔️ Opção 1 — usar Live Server (mais fácil) No VS Code: Clique com botão direito no index.html Clique em "Open with Live Server" Vai abrir algo assim: http://127.0.0.1:5500/index.html ✔️ Pronto — o vídeo vai funcionar
